# Smart Task Scheduler & Workflow Automation Engine

A Java Spring Boot based workflow automation system that helps users manage tasks, automate schedules, create workflows, monitor task execution, and improve productivity.

**Dhanush Pillai**

# Features

## Authentication
- User Registration
- User Login
- Secure Password Storage

## Task Management
- Create Task
- Update Task
- Delete Task
- Task Categories
- Due Dates
- Priority Levels
- Task Status

## Workflow Engine
- Task Dependencies
- Automatic Execution Order
- Background Processing

## Scheduler
- Scheduled Task Execution
- Reminder Notifications
- Daily Task Monitoring

## Reports
- Dashboard
- Activity Logs
- Task Statistics

## Search
- Search Tasks
- Filter by Category
- Filter by Priority
- Filter by Status
